# Stock Market Analysis and Prediction

## Introduction

**Stock Market Analysis and Prediction** is a data driven project focused on stock market analysis, visualization, risk assessment, and price prediction using historical market data.

The project explores historical data from major technology companies and other stocks to study market behavior through:

- Technical and statistical analysis
- Historical market data visualization
- Risk measurement, including Value at Risk (VaR)
- Monte Carlo simulation
- Experimental stock price prediction
- Comparative analysis of stock performance

## Purpose

The goal of this project is to explore how programming, statistics, and data analysis can be applied to financial markets.

Rather than focusing on a single prediction method, the project brings together multiple approaches to understand stock behavior, evaluate historical performance, measure risk, and investigate possible future price scenarios.

It serves as both a learning project and an experimental framework for studying concepts from:

- Data analysis and data mining
- Statistics and probability
- Financial analysis
- Risk management
- Data visualization
- Predictive modeling

## Project History

This project began in **2016**, when I was first introduced to the stock market and started learning about stocks, market data, technical analysis, and statistical methods for studying market behavior.

What began as a learning exercise gradually developed into a practical data analysis project. I experimented with historical market data, visualization techniques, risk analysis, and different approaches to stock price prediction.

The project was later revisited and used as a **college project in 2021**.

Since then, the original Python environment, dependencies, and data sources have become outdated. The original implementation relied on Google Finance through `pandas-datareader`, which is no longer available in the form required by the original code.

The results and observations from the original experiments have been preserved separately, including in the project's notebooks. These materials serve as a reference for understanding the original implementation and its results during the modernization process.

## Vision

The long term goal is to transform the original learning project into a practical and maintainable stock market analysis platform.

The modernized version aims to combine:

- Reliable market data
- Technical analysis
- Statistical analysis
- Risk assessment
- Predictive modeling
- Historical backtesting
- Data visualization

Each approach should be evaluated against historical data and realistic testing conditions rather than relying solely on theoretical assumptions.

The modernization will be carried out incrementally, preserving the original ideas while introducing current technologies, improved data sources, better testing, and more reproducible analysis.

Ultimately, the goal is to build a tool that can help analyze current market data, measure potential risks, compare analytical and predictive approaches, and provide useful insights for research and experimentation.

## Current Status

**Status: Original implementation preserved and modernization in progress**

The repository currently contains the original implementation. It represents the project as it existed during its earlier development and should not yet be considered a fully functional modern stock market analysis application.

The original code depends on an outdated software environment and data pipeline. As a result, it requires updates to work with current Python versions, libraries, and market data providers.

The original project was developed using the tools and libraries available at the time:

- **Python 2.7**
- **NumPy**
- **Pandas**
- **Matplotlib**
- **Seaborn**
- **pandas-datareader**
- **Google Finance** for historical market data
- **Monte Carlo simulation** for experimental stock price prediction

This stack is documented to preserve the project's original technical environment. During modernization, each component will be reviewed and replaced or updated where appropriate.

## Disclaimer

This project is an educational and experimental exploration of financial data analysis, statistics, risk modeling, and prediction.

Financial markets are inherently uncertain, and historical performance does not guarantee future results. Predictions and simulations produced by this project are experimental estimates and should not be interpreted as reliable forecasts.

This project is intended for learning, research, experimentation, and software development. It is not financial advice and should not be used as the sole basis for investment or trading decisions.
